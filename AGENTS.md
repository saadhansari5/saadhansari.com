# Personal blog

This is Saad Ansari's independent personal blog for saadhansari.com.
It has its own Git repository, deployment, and dependencies. It is separate from Partake.
Do not reuse or change Partake code, branding, credentials, or deployment settings.

Use Astro with MDX and GitHub Pages. Keep layouts and interactive components reusable.
Use the accepted simple editorial layout with light/dark mode. Keep the blog empty until the user supplies writing or asks for content. Do not add sample posts, ring motifs, or map decoration.
Use Markdown for regular posts and MDX for interactive pieces. Keep unfinished drafts in the Git-ignored drafts/ directory; the repository itself is public.
Run `npm run build` before publishing source changes. Pushes to main publish the site.
